# DOM Store — Стыбаев

Интерактивная страница магазина на чистом JavaScript и DOM API без фреймворков.

## Как открыть

1. Скачать или клонировать репозиторий.
2. Открыть файл `index.html` в браузере.
3. Для разработки удобно открыть папку проекта в VS Code.

## Что реализовано

Товары представлены объектами класса `Store` с полями `name`, `price` и `qty` и отрисовываются в DOM. Форма добавления обрабатывает событие `submit`, а ошибки валидации выводятся рядом с соответствующими полями без `alert`. Для изменения количества и удаления товара используется делегирование событий: один обработчик `click` установлен на контейнер списка и определяет действие по `data-action`. После добавления, удаления или изменения количества список и общий `total` пересчитываются без перезагрузки страницы.
